## Categories

The Learning Library is organized into four primary categories.

**Courses** provide structured, multi-section learning experiences that walk entrepreneurs through complex topics from start to finish. These are designed to be completed over multiple sessions and include exercises, templates, and self-assessment checkpoints.

**Templates** offer ready-to-use frameworks and fillable documents that entrepreneurs can customize for their own businesses. These save time by providing professional structures that have been proven effective.

**Guides** deliver focused, in-depth explorations of specific topics relevant to the entrepreneurial journey. Each guide combines research, best practices, and actionable advice in a format that can be read in a single sitting.

**Resources** are reference materials, checklists, and compliance documents that entrepreneurs can return to repeatedly as they navigate specific requirements or processes.

## How to Use These Resources

Each PDF in the Learning Library is designed to be both a standalone resource and part of a larger learning journey. Entrepreneurs at the **launch stage** should begin with the Business Plan Template and Louisiana Business Compliance Checklist. Those in the **growth stage** will benefit most from the Grant Writing Masterclass, Financial Literacy course, and Marketing guide. The Mental Wellness guide and PROOF Credential System are valuable at every stage of the entrepreneurial journey.

All documents feature the DowUrk FramewUrk branding, professional formatting with tables and structured sections, and a consistent design language that reflects the organization's commitment to quality and accessibility.
